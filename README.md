### Weather API Applications (Python)
This repository contains two Python applications that interact with the OpenWeatherMap API to retrieve and display weather data. These programs demonstrate API integration, JSON parsing, environment variable usage, input validation, and structured error handling.

### 📂 Files
#### current_weather.py

Prompts the user for a city, state, and country code

Uses the Geocoding API to retrieve coordinates

Fetches and displays the current temperature

Implements input validation and structured error handling

#### weather_forecast.py

Retrieves a 5-day forecast for Minneapolis, MN

Parses temperature, weather description, wind speed, and timestamps

Formats Unix timestamps into readable date/time output

Includes comments for adding additional error handling
